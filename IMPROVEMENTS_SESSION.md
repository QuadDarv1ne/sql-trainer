## План из 5 пунктов

### 1. Горячая клавиша Ctrl+B для переключения боковой панели

**Проблема:** Боковая панель (sidebar) переключалась только через кнопку в хедере. На десктопе не было быстрого способа открыть/закрыть панель клавиатурой.

**Решение:** Добавлен обработчик `Ctrl+B` (или `Cmd+B` на macOS) в `src/app/(main)/app/page.tsx` для toggle `sidebarOpen`.

**Файл:** `src/app/(main)/app/page.tsx`

---

### 2. Копирование SQL-решения в буфер обмена

**Проблема:** В панели задания была кнопка "Использовать решение" (подставляет SQL в редактор), но не было кнопки копирования SQL в буфер обмена для использования в другом месте.

**Решение:** Добавлена кнопка "Copy SQL" рядом с "Use Solution" в `src/components/task-panel.tsx`. Используется `navigator.clipboard.writeText()` с уведомлением через toast.

**Файл:** `src/components/task-panel.tsx`

---

### 3. Отображение количества строк в заголовке результатов

**Проблема:** В заголовке таблицы результатов отображалось время выполнения, но количество строк показывалось только в левой части. Дублирование в заголовке упрощает чтение для больших результатов.

**Решение:** Добавлен бейдж с количеством строк рядом с временем выполнения в `src/components/results-table.tsx`.

**Файл:** `src/components/results-table.tsx`

---

### 4. Горячая клавиша Ctrl+Shift+D для переключения темы

**Проблема:** Переключение темы (светлая/тёмная/системная) было доступно только через кнопку в хедере. Не было клавиатурного.shortcuts для этого действия.

**Решение:** Добавлен обработчик `Ctrl+Shift+D` для циклического переключения темы: light → dark → system.

**Файл:** `src/app/(main)/app/page.tsx`

---

### 5. Обновление справки по горячим клавишам

**Проблема:** Новые горячие клавиши (Ctrl+B, Ctrl+Shift+D) не были документированы в справке по shortcuts.

**Решение:** Добавлена новая секция "Interface" в `src/components/shortcuts-help.tsx` с описанием новых горячих клавиш.

**Файл:** `src/components/shortcuts-help.tsx`
